# Paul Timilehin — Portfolio

A static, multi-page product design portfolio built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — portfolio landing page
- `about.html` — about page
- `applyflow.html` — Applyflow case study
- `fitfuel.html` — FitFuel case study
- `profitpulse.html` — ProfitPulse case study

The site has no build step. Netlify publishes the project root as configured in `netlify.toml`.
